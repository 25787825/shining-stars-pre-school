First-time Admin Setup Instructions
  1. Run supabase/schema.sql in your Supabase SQL Editor.
  2. Create your staff user in Supabase Dashboard → Authentication → Users → Add user.
  3. Grant that user admin portal access in the SQL Editor:
    insert into public.staff_admins (user_id, email) select id, email from auth.users where email = 'your-admin@email.com';
